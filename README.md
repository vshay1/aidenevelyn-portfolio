Aiden Evelyn - Portfolio
A full-stack portfolio website showcasing programming projects, writing, artwork, and photography with a secure admin dashboard.

Features
Portfolio Showcase - Projects, writing, art, and photography

Secure Admin Dashboard - Two-factor authentication with secret key

One-Time Admin URLs - Unique, self-destroying admin links

Supabase Database - Cloud-hosted PostgreSQL

Analytics Tracking - Page visits and admin session logging

Responsive Design - Works on all devices

Tech Stack
Backend: Flask, Flask-SQLAlchemy, Flask-Login

Database: PostgreSQL (Supabase) / SQLite (local)

Frontend: HTML5, CSS3, Vanilla JavaScript

Deployment: Railway / Render / Vercel ready

Prerequisites
Python 3.11+

Supabase account (or SQLite for local development)
